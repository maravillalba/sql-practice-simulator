# SQL Exam Simulator

Simulador interactivo para practicar consultas SQL mediante preguntas tipo examen.

## 🚀 Características

- Preguntas de SQL
- Simulación de examen
- Interfaz web simple
- Ideal para practicar bases de datos

## 🧠 Tecnologías

- HTML
- CSS
- JavaScript

## 🎯 Objetivo

Practicar consultas SQL y preparar evaluaciones de bases de datos.
